## Key Concepts

### Region

A geographical AWS area containing multiple Availability Zones.

### Availability Zone

An isolated location within an AWS Region.

### Regional Services

Examples:

- EC2
- RDS
- VPC
- Lambda

### Global Services

Examples:

- IAM
- Route 53
