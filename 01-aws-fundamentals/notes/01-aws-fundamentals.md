# Day 1 — AWS Fundamentals

## AWS Region

An AWS Region is a geographical area containing multiple Availability Zones.

Examples include Mumbai, Singapore, and other AWS Regions around the world.

## Availability Zone

An Availability Zone (AZ) is an isolated location within an AWS Region.

Multiple AZs allow applications to be designed for higher availability and resilience.
